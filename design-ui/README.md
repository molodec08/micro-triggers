# Simple UI

Общая дизайн-система для приложений на Shopify App Store. Направление — "Polaris-корпоративный":
UI выглядит нативно внутри Shopify admin (это снижает трение для мерчанта), но не копирует Polaris один в один —
свои акцентный синий, тёплый (не стерильно-белый) канвас и шрифт Manrope вместо Inter дают отличимый почерк.

## Принципы

1. **Доверие важнее эффектности.** Аудитория — мерчанты, которые ставят лёгкий платный тул поверх магазина.
   Чем спокойнее и предсказуемее интерфейс, тем меньше сомнений при установке.
2. **Один акцент.** Синий (`--accent`) — единственный кликабельный/активный цвет. Остальное — нейтральные тона и
   семантические цвета (success/warning/danger) только для статуса, не для декора.
3. **Одна гарнитура, разные веса.** Manrope 400/500/600 — для заголовков и текста. Не эксплуатировать
   заглавные лейблы и произвольные акценты одним словом.
4. **8px-сетка.** Все отступы кратны `--space-*` токенам.
5. **Карточка листинга = карточка админки = карточка виджета на витрине.** Один и тот же визуальный язык
   (radius, тени, отступы) должен читаться во всех трёх местах, где мерчант видит продукт.

## Структура

```
src/
  tokens.css        — цвета, типографика, отступы, радиусы (CSS custom properties, light+dark)
  tokens.ts          — те же значения в TS, для случаев когда нужен raw value (canvas/svg/charts)
  components.css     — базовые классы: .s-btn, .s-card, .s-badge, .s-listing-card, .s-trigger-bar
  components/
    Button.tsx
    Card.tsx (+ Badge)
    ListingCard.tsx  — компонент под будущую карточку в Shopify App Store
preview.html          — статичный превью без сборки, открыть в браузере
```

## Как подключить в существующий React/TS/Vite проект

1. Скопируй `src/tokens.css` и `src/components.css` в свой проект (например в `src/styles/`).
2. Импортируй их один раз в корне приложения:
   ```ts
   import "./styles/tokens.css";
   import "./styles/components.css";
   ```
3. Скопируй `src/components/*.tsx` — они завязаны только на классы из `components.css`, без внешних зависимостей.
4. Подключи шрифт Manrope (Google Fonts, как в `preview.html`), либо замени `--font-body` на системный стек,
   если не хочешь тянуть веб-шрифт в лёгкое приложение.
5. Для тёмной темы — выставляй `data-theme="dark"` на корневой элемент.

## Что дальше

- Применить `.s-listing-card` / `ListingCard.tsx` к реальным ассетам в Shopify App Store
  (иконка приложения, скриншоты, промо-картинка) — иконка должна использовать `--accent` и `--accent-soft`.
- Перенести админку Micro Triggers на эти токены и компоненты.
- Как только появится второе приложение — токены и компоненты просто копируются, а не переизобретаются.
