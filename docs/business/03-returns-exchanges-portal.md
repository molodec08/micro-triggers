# Идея 3: Возвраты и обмены — self-service портал

← [Обзор](./00-overview.md)

## Проблема и аудитория

Горизонтальная потребность: большинство мелких магазинов обрабатывают возвраты вручную по email, что отнимает время и создаёт плохой опыт для покупателя. Острая, хорошо осознаваемая мерчантом боль — выше шанс конверсии в установку по сравнению с "приятными, но не обязательными" фичами.

Аудитория: магазины с физическими товарами и регулярным потоком возвратов (одежда, обувь, товары с размерной сеткой особенно остро нуждаются).

## MVP-функционал

- Публичная форма для покупателя: ввод номера заказа → выбор товара(ов) → причина возврата/обмена
- Настраиваемые мерчантом правила: окно в днях, какие категории/товары подлежат возврату, автоматическое одобрение vs. модерация
- Генерация return label (опционально, через интеграцию с курьерской службой) или инструкция для самостоятельной отправки
- Дашборд для мерчанта: статус каждого возврата, причины (для анализа продукта)

## Техническая реализация

- Remix + Polaris, Node.js/PostgreSQL
- GraphQL Admin API — для создания return/refund через встроенные Shopify Returns объекты (Shopify имеет нативную поддержку возвратов в Admin API, стоит опираться на неё, а не изобретать параллельную сущность)
- Webhook `orders/fulfilled`, `refunds/create` — синхронизация статусов
- Логика правил — отдельная таблица `return_policies` (окно дней, категории-исключения) привязанная к shop_id

## Монетизация

$15–39/мес — выше, чем у более простых триггер-приложений, так как продукт закрывает более дорогостоящую операционную боль.

## Конкуренты

Loop Returns, AfterShip Returns, Return Prime — сильные игроки. Дифференциация: простота для малого мерчанта без сложной ERP-интеграции, которая нужна крупным брендам.

## Риски

- Технически самая сложная из пяти идей — больше edge cases (частичные возвраты, обмен на другой размер/товар, интеграция с оплатой при разнице в цене)
- Прямое взаимодействие с деньгами (refunds) требует более тщательного тестирования и осторожности при review в App Store
