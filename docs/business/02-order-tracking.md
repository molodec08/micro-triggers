# Идея 2: Order tracking — брендированная страница трекинга + проактивные уведомления

← [Обзор](./00-overview.md)

## Проблема и аудитория

Полностью горизонтальная потребность — нужна любому магазину независимо от ниши. Решает "where is my order" (WISMO), которая генерирует значительную долю обращений в поддержку — а поддержки как отдельного инструмента нет у 98.5% магазинов.

Аудитория: любой Shopify-мерчант с регулярной доставкой физических товаров.

## MVP-функционал

- Брендированная страница трекинга под доменом/темой магазина (не редирект на сайт курьерской службы)
- Email/SMS-уведомления при смене статуса доставки (принято к отправке → в пути → доставлено)
- Простая агрегация статусов от нескольких курьерских служб в единый вид
- Виджет "Где мой заказ" в аккаунте покупателя на сторфронте

## Техническая реализация

- Remix + Polaris (админка настроек), Node.js/PostgreSQL
- Webhook `fulfillments/create`, `fulfillments/update` — триггер на смену статуса
- Опционально интеграция с courier tracking API (AfterShip API, 17TRACK API) вместо парсинга каждой службы вручную — экономит время разработки на старте
- Theme App Extension для встраивания трекинг-блока на сторфронт

## Монетизация

$9–29/мес по тирам (лимит по числу заказов/уведомлений в месяц).

## Конкуренты

AfterShip, Track123 — сильные и функциональные, но дорогие и избыточные для маленького магазина. Возможность зайти с простым дешёвым тарифом без лишних фич (аналитика перевозчиков, мультиязычность и т.п.), которые нужны только крупным.

## Риски

- Зависимость от стороннего tracking API (стоимость, лимиты, точность данных по мелким региональным курьерам)
- Первое впечатление сильно зависит от полноты покрытия курьеров — недостающая интеграция с популярной службой в конкретном регионе мерчанта = моментальный отказ от установки
